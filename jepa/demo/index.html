What the vocabulary filter does

The world model can only name actions through Meta's EPIC-KITCHENS probe, whose output layer has one row per verb () and per noun (). A tag is known when it lands on one of those rows:

  1. the word is a class name itself (cut, onion), or
  2. EPIC-KITCHENS' annotators listed it as a synonym of a class (whisk → mix, crack → break, chop → cut; ), or
  3. for nouns, its singular or its head noun is (chillies → chilli, cottage cheese → cheese).

Anything else has no row in the model's output, so the world model could never predict it and the tag is dropped. Try a word:

Exact prompt sent, and where the word lists come from

The verb and noun lists are the probe's output classes: the class names in EPIC-KITCHENS' EPIC_100_verb_classes.csv / EPIC_100_noun_classes.csv that occur in a (verb, noun) action of EPIC_100_train.csv, the same rule Meta's code uses to build the probe's output layer. They are sorted alphabetically and pasted into the prompt.
